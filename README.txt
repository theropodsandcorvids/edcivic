SIX CIVIC CURRICULUM PORTFOLIO WEBSITES · VERSION 1.2
Extract the ZIP and open index.html to choose a design.
Each numbered directory is a complete nine-page website with its own docs/ downloads.
No build step or server runtime is required. Fonts and document preview images are embedded.

To host all six: upload this entire bundle, preserving the directories.
To host one only: upload that design folder's contents; remove the top design switcher
or update its links if the other design folders will not be hosted alongside it.

Each design contains seven work samples, an Other work page, 13 PDFs, an editable project-tracker CSV
and an interactive method-picker prototype. Other work placeholder images await the candidate's files.
Seattle is a real historical case sourced to WWC and its implementation partner.
Evaluation metrics and tracker statuses are simulated. Candidate history is not invented.
Before applying: replace gray italic candidate-profile markers and add the approved resume.
The micro-course is a browser prototype, not an LMS or SCORM package.
